Optional complete Scripture data asset:
- Filename: complete-bible.json
- Format: JSON array of objects with translation, book, chapter, verse, text.
- Intended translation: World English Bible (WEB), public domain according to eBible.org.
- Preserve the translation text exactly if using the World English Bible name.
- The application imports this asset into Room on first launch when the WEB verse table is empty.
- The app contains no complete Bible text by default; the user/developer must add the verified source asset.
